# Sampling design and source-document provenance
This English document replaces the repository's inherited Chinese sampling note. Raw compressed block data and the calendar retain their original bytes. The source note is preserved in the supplied desktop dataset and earlier Git history.

## Current study
The observation window is November 16, 2023, 00:00 UTC inclusive through November 16, 2026, 00:00 UTC exclusive, covering 1,096 dates. Twelve consecutive three-month phases each contain separate weekday and weekend strata. Seed 20231116 draws four weekdays and two weekend dates without replacement per phase. Ethereum Mainnet, OP Mainnet, and Arbitrum One share the resulting 72 dates. All collected blocks satisfy 12:00 UTC <= timestamp < 13:00 UTC.

Each date has a known positive inclusion probability within its phase and weekday/weekend stratum. The probability sample covers protocol and weekly variation at a fixed hour. Phase-level gas ranks describe the observed sample. They are not full-population quintile days. In the current paper, each phase's six hours form three rank groups of two hours per chain, with earlier dates breaking ties.

The supplied calendar includes four additional event dates. March 12 and March 14, 2024 surround Dencun and are retained separately. November 7 and November 14, 2026 were specified for a Base event and are outside this three-network analysis. The archive contains 76 files per chain, or 228 chain-hours. The probability analysis uses 216 chain-hours. Including the separate Dencun sample gives 222 retained chain-hours.

## Translation of inherited design statements
The original note used the same three-year window, twelve phases, fixed hour, and seed. It described four networks, including Base, giving 76 dates and 304 planned chain-hours. It proposed collecting 29 base fields and selecting five-minute windows by a common rule. It referred to a calendar under Stratified_12x6_12_13_UTC generated by sample_calendar.py.

Those inherited four-network counts and five-minute selection statements describe an earlier plan, not the three directories delivered here. The repository's data/raw/sampling_calendar.csv and actual network directories define the supplied observations. The current weighted layout experiment uses whole sampled hours and a shared 36-date training/36-date test split per network.
