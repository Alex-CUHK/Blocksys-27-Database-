Final figure reproduction
Install the recorded numpy and matplotlib dependencies in a Python environment.
Run scripts/plot_workloads.py --source /path/to/data/raw to regenerate audited hourly inputs from the 72 probability dates on each network.
Run scripts/plot_workload_combined.py for the six-panel descriptive Figure 1.
Run scripts/plot_transaction_mix_shared.py for the common-axis transaction composition.
The correlations plot is generated by plot_workloads.py.
The weighted matrix plot comes from experiment/outputs/workload_weighted/figure2_matrices.pdf in the GitHub repository.
For regenerated weighted experiments, use scripts/rebuild_layout_figures.py at the GitHub repository root to sync matrices and summaries before rebuilding the extended sweep and final eight-panel figure.
The retained plot_weighted_combined.py generates an auxiliary sensitivity figure described in prose in the final paper. It is not currently included in the manuscript.
Do not run update_descriptive_tables.py as a manuscript editor: it is an older helper and may restore superseded table captions. Numerical source artifacts are retained for checking.
